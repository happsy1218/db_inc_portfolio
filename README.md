# DB Inc. S/W Engineer Portfolio — 박소윤

GitHub Pages 업로드용 최종본입니다.

## 업로드 구조

```text
repository-root/
├─ index.html
├─ .nojekyll
└─ assets/
   ├─ profile.png
   ├─ scada_architecture.png
   ├─ scada_screen.png
   ├─ amhs_architecture.png
   ├─ amhs_screen.png
   ├─ info_architecture.png
   ├─ info_screen.png
   ├─ vision_architecture.png
   └─ vision_screen.png
```

## GitHub Pages 배포
1. 이 폴더 안의 `index.html`, `.nojekyll`, `assets` 폴더를 저장소 루트에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch를 `main`, Folder를 `/(root)`로 지정한 뒤 저장합니다.
5. 잠시 후 표시되는 Pages URL로 접속합니다.

> `index.html`만 단독 업로드하지 말고 `assets` 폴더도 반드시 함께 올려야 이미지가 표시됩니다.
