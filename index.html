시각 자료

Troubleshooting · 판정은 맞는데 분류 타이밍이 어긋난 문제

PROBLEM

AI 결과는 정상인데 박스가 예상 위치와 다른 시점에 분류됨.

ANALYSIS

판정 → 발행 → 수신 → 제어 시작 → 복귀 로그를 단계별 비교.

ROOT CAUSE

통신 문제 하나로 단정하지 않고 메시지 전달과 모터 구동 편차를 분리.

SOLUTION

수신 확인 응답, 복귀 상태 관리, 전원 구성을 보완.

VALIDATION

정상·불량·재검사 박스를 반복 투입하며 전체 흐름을 재검증.

Retrospective — 로그를 관측 가능한 시스템으로 확장한다면

당시 부족했던 점

문제 해결용 단계별 로그는 효과적이었지만 지연시간을 구조적으로 누적·분석하는 체계까지 만들지는 못했습니다.

지금 다시 한다면

메시지마다 동일 ID와 타임스탬프를 남겨 구간별 latency와 실패율을 자동 집계하겠습니다.

현재 역량으로 확장

운영 화면에 통신 상태·장치 응답·최근 실패 이력을 함께 노출해 원인 추적 시간을 줄이는 기능으로 확장하겠습니다.
